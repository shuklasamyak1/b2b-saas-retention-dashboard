# b2b-saas-retention-dashboard
B2B SaaS Revenue &amp; Churn Intelligence Engine built with PostgreSQL &amp; Power BI. Modeled a star schema tracking €49K ARR and engineered DAX measures for Active MRR, Cancelled MRR, and Churn Rate %. Features interactive time-series retention curves, sector breakdowns, dynamic page navigation, and drill-through tooltips.
